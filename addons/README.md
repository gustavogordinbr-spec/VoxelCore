# Add-ons

Coloque aqui arquivos `.mcaddon`, `.mcpack` ou `.zip`, ou use:

```bash
./voxelcore install-addon /caminho/MeuAddon.mcaddon
```

O instalador lê cada `manifest.json`, separa behavior packs e resource packs e
atualiza os arquivos de ativação do mundo. Add-ons que exigem recursos
experimentais ainda precisam de um mundo criado/exportado com esses
experimentos habilitados.

Não publique add-ons de terceiros sem autorização do autor.
